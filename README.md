# Strain-gradient-induced iodide-vacancy accumulation in CsPbI3

Processed data and plotting code accompanying **Multiphysics Modeling Reveals Strain-Gradient-Induced Iodide-Vacancy Accumulation in CsPbI3 Perovskite**, by Jun-Jie Li, Chuan-Xin Cui, and Jin-Wu Jiang.

The package contains the numerical data used for Figures 3-10, drawing scripts for Figures 1-10, reference figure PDFs, convergence summaries, and a 64-case parameter matrix. The plotting scripts use the included tables; running them does not require COMSOL or access to the authors' original project directories.

## Run the plotting scripts

Use Python 3.12 with the packages listed in `requirements.txt`. The complete figure workflow was verified on Windows with Python 3.12.14, NumPy 2.5.4, Matplotlib 3.11.2, and TeX Live 2025. From the package root:

```shell
python -m pip install -r requirements.txt
python scripts/reproduce_all.py
```

The entry point first checks the released tables, cross-figure consistency, and file checksums, then writes PNG and PDF outputs to `reproduced_figures/`. The reference PDFs in `figures/` are preserved. Individual figures can be generated with, for example:

```shell
python scripts/figure5.py --output-dir reproduced_figures
```

To check the data and package integrity without drawing figures or requiring third-party Python packages:

```shell
python scripts/validate_data.py
```

**Figure 2 additionally requires a working LaTeX installation**, including the `amsmath`, `bm`, `type1cm`, and `type1ec` packages and Matplotlib's TeX rendering dependencies. The `latex` and `dvipng` executables must be available on the command search path. To generate only the numerical-result figures without this external LaTeX dependency:

```shell
python scripts/reproduce_all.py --figures 3-10
```

The other figures use Matplotlib's text and math rendering. Times New Roman is preferred where available, with a serif fallback on other systems. Fonts and plotting-library versions can change text placement slightly; the included reference PDFs provide the manuscript appearance.

## Baseline and numerical checks

The baseline has `T = 600 K`, applied strain `epsilon_0 = -0.08`, initial vacancy concentration `c0 = 2.002 mol m^-3`, length `L = 300 nm`, and height `H = 100 nm`. Additional baseline parameters are in `data/benchmark/paper_flux_model_parameters.csv`.

The reported baseline settling time is **9.203 ms**, corresponding to the stored value `0.009202752029406014 s`. It is the first saved time after which the discrete Euclidean residual `norm(C(t)-C_final)/norm(C_initial-C_final)` remains at or below `1e-4`. Figure 5 includes the residual history, and `data/benchmark/paper_flux_plot_provenance.json` records the criterion and snapshot times.

The mesh error of approximately **0.0054%** is the `profile_max_difference_tmax_percent` value for `mesh_base_vs_fine` in `data/convergence/convergence_metrics.csv`. The time-step error of approximately **0.0063%** is the `profile_max_difference_all_times_percent` value for `dtmax_vs_quarter_dtmax` in the same table. These summarize different comparisons: a final spatial profile and all matching saved times, respectively.

The convergence case summaries use their own 721-time, 0-0.1 s protocol and a maximum pointwise relative residual. Their `strict_steady_time_s` values are not the baseline Euclidean settling time used in Figures 5-7.

## Data scope and provenance

This package supports inspection of the reported results and reconstruction of the figures from processed data. It does not include COMSOL model files, Java model-building programs, atomistic simulation inputs, complete trajectories, or all upstream COMSOL exports. The Figure 8 theoretical profiles and Figure 10 analytical curves are supplied in the tables; the plotting entry point reads these values rather than rerunning their upstream numerical solvers.

Figure 3 retains the original calibration quantities and processing notes. In particular, `D_V_m2_s` is the vacancy diffusivity obtained from vacancy mean-squared displacements. The formation-energy and migration-barrier points originate from the atomistic work described and cited in the manuscript.

Figure 5 includes all saved two-dimensional nodes for four displayed times. In each two-dimensional series, shared time, case, and provenance metadata appear only in the first row and apply to all nodes in that series; see `data/README.md` for the exact inheritance rules. The upstream standalone two-dimensional export named in its provenance was unavailable when this package was prepared; the included numerical snapshot is sufficient for the supplied rendering, but does not supply that missing upstream file.

`PROVENANCE.csv` records source identifiers, availability, and upstream checksums. Source hashes refer to the original upstream files; use `SHA256SUMS` to verify the files in this package. See `data/README.md` for the provenance conventions.

The repository's `.gitattributes` uses `* -text` to disable Git line-ending normalization and preserve the file bytes covered by `SHA256SUMS` across checkouts.
